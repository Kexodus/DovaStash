Dova Stash changelog

0.2.2
- Sort on arrival: with menus that pause the game, items put into the master are sorted when it closes; only Skyrim Souls (unpaused menus) sorts while it is open.
- Respawning containers are accepted only where the area never resets; "player house" is checked on the cell's own location only.
- Plain-copy moves no longer run while a tempered, enchanted, renamed or worn copy of the same item stays behind (the engine could hand over the special one).
- Thread safety: the HUD, activate prompt and QuickLoot read a published copy of the home and settings; the UIExtensions bridge is locked.
- Default keep rules are never written over an unreadable Settings.json, and are saved atomically.
- Logging defaults to info again. The unused I4 rule loading is gone (faster start).

0.2.1
- QuickLoot IE: one category icon per bound category in the bottom-right corner; master shows "Master".
- Settings page: hover help naming each INI key, options greyed out when unavailable, reset to defaults.
- Activate prompt label on the name line; floating icons off by default and no longer blink.

0.2.0
- QuickLoot IE integration, UIExtensions list menus (any skin) with in-game rename, every setting editable in game without a restart, keep rules for every home, sort on arrival, activate-prompt roles, floating icons.

0.1.0 - first public release (release candidate)
- Master container per home: Deposit, Distribute on master close, Sort all, and Retrieve (everything or by category).
- 37 keyword-driven default categories in JSON (Categories/00_Default.json). Add-on category packs load in name order.
- Learned destinations: placing an item in a container by hand makes that container its destination.
- 22 home templates: Breezehome, Honeyside, Hjerim, Proudspire Manor, Vlindrel Hall, Severin Manor, Lakeview Manor, Heljarchen Hall and Windstad Manor (each Hearthfire house with its cellar), plus 10 Creation Club homes.
- Template notice on entering a home, with optional auto-enable (bAutoEnableTemplates). Re-apply template keeps learned destinations, keep rules, ignored containers and containers you added yourself. A timestamped backup is written first.
- Keep rules: built-in defaults (equipped, favorited, quest, gold, lockpicks, torches), optional global Settings.json, per-home always/never rules and quotas.
- SKSE Menu Framework panel (SE/AE): Actions, Containers, Learned, Keep rules and Template export tabs, plus Current home, Settings, Templates, Diagnostics and About pages.
- Native message-box interface, used as the fallback and on VR.
- Safety: ownership and respawn checks, disabled (unbuilt) containers skipped, warnings for scripted containers, extra data preserved on every move, layouts backed up on reset, broken layout files never overwritten.
- One DLL for SE 1.5.97, AE 1.6.x and VR (VR experimental). No ESP.

Planned (not in 0.1.0): crafting from storage, central storage across homes.
