# Dova Stash art set

Vector art for the Nexus Mods page and the GitHub repository. Every image is authored as HTML/SVG in
`src/` and rendered to PNG in `out/` with headless Microsoft Edge, so the whole set can be rebuilt offline.

## Art direction

- **Black, white and neutral grays only.** No color and no sepia. `render.py --check-gray` decodes every
  PNG and fails if any pixel has R, G and B that differ.
- **Minimal.** Generous negative space, wide-tracked capitals, and nothing that isn't the message: no
  platform or version tags, no ornaments, no counts or signatures. Icons are straight-line,
  square-capped and miter-joined, so they look carved.
- **Original mark.** The emblem is a longhouse gable with crossed horns over a three-bay chest, inside a
  chamfered square frame. It is not based on any Bethesda or Skyrim logo. The set contains no
  screenshots or game assets.

The tokens and the type scale are CSS variables in `src/style.css`.

## Fonts

Both fonts use the SIL Open Font License 1.1. They were downloaded from
[github.com/google/fonts](https://github.com/google/fonts) into `fonts/`, each with its license file, and
are loaded with `@font-face` from those local files.

| Font | File | License | Role |
|---|---|---|---|
| Cinzel (variable) | `fonts/Cinzel-VF.ttf` | `fonts/OFL-Cinzel.txt` | Wordmark, titles. Its flared, inscriptional capitals read as carved, and wide tracking gives them a Nordic stillness. |
| Jost (variable) | `fonts/Jost-VF.ttf` | `fonts/OFL-Jost.txt` | Taglines, captions and lists. A clean geometric sans that stays legible when the images are scaled down. |

The fonts are registered under private family names (`DS Cinzel`, `DS Jost`), so no
installed system font can stand in for them. `src/common.js` hides each page until both faces have
loaded. If any face fails to load, the page is covered with a striped "FONT FALLBACK" overlay, so a
fallback font cannot slip into a render unnoticed.

## Re-rendering

Requirements: Windows with Microsoft Edge and Python 3.10 or later (stdlib only).

```
python -I nexus/art/render.py                 # render everything into nexus/art/out/
python -I nexus/art/render.py --check-gray    # also verify that no pixel has color
python -I nexus/art/render.py header_ icon_   # render only outputs whose name contains a filter
```

Set `DS_EDGE` to use a different Edge or Chrome executable. The script:

1. regenerates `src/data.js` from `dist/Data/SKSE/Plugins/DovaStash` (template `name` fields and default
   categories), so the homes and categories galleries always match what ships;
2. screenshots each page with `--headless=new --force-device-scale-factor=1 --disable-lcd-text` (grayscale
   text antialiasing) and `--allow-file-access-from-files` (pages inline the SVGs from `src/icons/`);
3. checks each PNG: the IHDR width and height, a real alpha channel with clear corners on `*_transparent`
   files, and a size under 1.5 MB.

### Source layout

| Path | Contents |
|---|---|
| `src/style.css` | Palette, type scale, icon and emblem styles |
| `src/common.js` | Query parameters, font-load guard, `icon()` and `mark()` helpers |
| `src/icons/*.svg` | Line icons on a 256 grid (2 px non-scaling stroke) and `logo.svg` (the emblem) |
| `src/*.html` | One page per asset type. `header.html`, `icon.html` and `logo.html` take query parameters. |
| `src/data.js` | Generated by `render.py`. Do not edit. |

### Display notes

- Description images are designed to be shown scaled down to the width of the description column, and
  they stay legible at 50 % of their size.
- Feature icons have a 2 px stroke at 256 px. Show them at 256 px, or at 128 px for a finer 1 px line.
  Do not go smaller. Use `features_grid_1200x700.png` when you need all six at once.
- Everything is drawn on pure black so it blends into the Nexus dark theme. Use the `*_transparent`
  variants only on other backgrounds.
